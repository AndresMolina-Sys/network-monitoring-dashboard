# Fase `constitution`

Lee `docs/constitution.md` y responde con un resumen fiel de los principios pertinentes a la pregunta. No crees ni modifiques specs, planes, tareas o código.

Si el usuario solicita cambiar la constitución, identifica el texto y el impacto propuestos y solicita confirmación antes de editar. No sustituyas principios aprobados ni interpretes una solicitud de resumen como permiso para modificarlos. Registra cambios aprobados solo después de confirmación explícita; el coordinador aplica los requisitos de revisión, memoria y commit.
